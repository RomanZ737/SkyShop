# SkyShop
Проект онлайн магазина

На данный момент реализовано:
* два абстрактных класса: **BaseClass** и **BaseClassCategory**
* два основных класса **Product** и **Category** 
* два дочерних класса: **Smartphone**, **LawnGrass**
* один класс-итератор: **ProductIterator**
* один класс для создания заказов: **Order**

Для класса **Product** определите следующие свойства:
* название *name*
* описание *description*
* цена *price*
* количество в наличии *quantity*
Для класса **Product** создан класс-метод new_product, который принимает на вход параметры товара в словаре и возвращает
созданный объект класса *Product*
Для метода *new_product* реализована проверка наличия такого же товара схожего по имени. В случае если товар уже 
существует, складывается количество в наличии старого товара и нового. При конфликте цен выберается та, которая 
является более высокой.
* 
Переопределена функция сложения продуктов оно класса по алгоритму:
* Например, для товара 'a' с ценой 100 рублей и количеством на складе 10 и товара 'b' с ценой 200 рублей и количеством
на складе 2 результатом выполнения операции 'a' + 'b' должно стать значение, полученное из 100 × 10 + 200 × 2 = 1400.

Для класса **Product** атрибут цены сделан приватным и описаны геттеры и сеттеры.
В случае если цена товара понижается, добавлена логика подтверждения пользователем вручную через ввод y (значит yes) или 
n (значит no) для согласия понизить цену или для отмены действия соответственно.

Для класса **Category** определите следующие свойства:
* название *name*
* описание *description*
* список товаров категории *products*
Список категорий является приватным атрибутом. Для добавления товаров в категорию реализован специальный метод 
*add_product()*, который проверяет принадлежность доваров к родительскому или дочернему классу.
Реализован геттер, который выводит список товаров в виде строк в формате:
*Название продукта, 80 руб. Остаток: 15 шт.*

Для дочернего класса **Smartphone**, помимо родительских свойств реализованы следующие свойства:
* производительность (efficiency)
* модель (model)
* объем встроенной памяти (memory)
* цвет (color).

Для дочернего класса **LawnGrass**, помимо родительских свойств реализованы следующие свойства:
* страна-производитель (country)
* срок прорастания (germination_period),
* цвет (color).

Класс-итератор **ProductIterator**:
*Принимает экземпляр класса Category. Возвращает итератор объектов категории*

Класс-итератор **Order**:
*Класс служит для создания заказов*

В конреновом каталоге функция **main**, которая инициализирует описанные выше классы, а также *загрузка данных из файла json*

Для всех функция реализованы основные тесты.
