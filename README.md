# SkyShop
Проект онлайн магазина

На данный момент реализована создание двух классов: **Product** и **Category**.

Для класса **Product** определите следующие свойства:
* название *name*
* описание *description*
* цена *price*
* количество в наличии *quantity*

Для класса **Product** определите следующие свойства:
* название *name*
* описание *description*
* список товаров категории *products*

В конреновом каталоге функция **main**, которая инициализирует описанные выше классы, а также *загрузка данных из файла json*

Для всех функция реализованы основные тесты.
